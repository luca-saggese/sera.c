# M0 — Qwen3-32B Q4: GGUF mmap + fast CUDA load su GB10

## 0. Obiettivo

Costruire esclusivamente la base del nuovo runtime Qwen3-32B Q4 su NVIDIA GB10:

```text

   ↓

   ↓

   ↓

   ↓

   ↓
```

1. aperto tramite `mmap`;
2. inventariato correttamente;
3. pianificato per la residency;

5. misurato con telemetry minima e utile.

# 8. Loader architecture obbligatoria

Mantenere il pattern già validato su GB10:

```text
mmap source
       ↓
stage[0] pinned ─┐
stage[1] pinned ─┤ double buffer
                 ↓
          cudaMemcpyAsync
                 ↓
        resident CUDA storage
```

Baseline iniziale:

```text
stage[0] = 128 MiB
stage[1] = 128 MiB
```

Se il donor attuale usa già una dimensione diversa e misurata, non modificarla subito: documentarla e usare quella per la prima baseline.

Il comportamento deve essere:

```text
CPU fills stage[0]
GPU copies stage[0]

while GPU copies stage[0]:
    CPU prepares stage[1]

event says stage[0] reusable

swap
```
