# M2 — Qwen3-32B Q4: complete one-pass forward on GB10

## 0. Obiettivo

M0 ha chiuso:

```text
GGUF
→ mmap
→ residency plan
→ fast CUDA load
→ stable resident device pointers
```

M1 ha chiuso:

```text
resident Q4_K matrix
×
device activations
→
production CUDA quantized linear
```

M2 deve arrivare al **forward completo del Qwen3-32B Q4**:

```text
token IDs
   ↓
embedding
   ↓
64 × transformer layer
   ↓
final RMSNorm
   ↓
candidate LM-head rows
   ↓
decision logits
```

Il risultato finale deve poter riprodurre i test semantici già eseguiti con Transformers senza usare:

```text
generate()
autoregressive decoding
sampling
CoT output
custom decision head
```

Target:

```text
one prompt
→ one forward
→ logits 1/2/3/4
→ decision
```

# 20. MLP

Pipeline:

```text
m = rmsnorm(x)

gate = gate_proj(m)
up   = up_proj(m)

activated = silu(gate) * up

down = down_proj(activated)

x = x + down
```

`gate` e `up`:

```text
[T,25600]
```

Non tenere copie inutili.

Riutilizzare workspace.

Il `SiLU × up` può essere un semplice fused elementwise kernel.

Non serve fondere:

```text
gate projection + SiLU
up projection + multiplication
```

in M2.
